1Les définitions

Dataset
Le fichier lu ou écrit, par exemple un classeur Excel.
Feature type
Un sous-ensemble d'enregistrements : une feuille, une couche, une table.
Feature
Une ligne, la plus petite pièce d'une traduction FME.
Attribut
Une colonne, l'information qui décrit la feature.
Workspace
Le contenu du canevas et du Navigator. Il garde la définition de la traduction, pas les données.
Donnée spatiale
Elle contient la géométrie (l'emplacement) et des attributs (la description). Format vecteur (point, ligne, polygone) ou raster (valeur d'un phénomène continu, comme l'altitude).

3Lire des données

Créer un workspace, puis ajouter un reader

Reader : Microsoft Excel

Quick Add liste tous les formats et transformers du FME Hub, y compris ceux des utilisateurs. Le paramètre Dataset accepte un ou plusieurs chemins, des URL ou une connexion à un service web.

Régler les paramètres du reader

Dans Excel, longitude et latitude sont des nombres. FME les lit comme x_coordinate et y_coordinate.

Choisir le système de coordonnées

LL84 = WGS84 = EPSG:4326

FME le lit tout seul s'il est dans les données, sinon il vaut Unknown. Ce n'est pas obligatoire, mais il faut le renseigner pour un fond de carte ou pour comparer des données. Les trois noms ci-dessus désignent le même système (GPS).

Enregistrer, puis lancer le workspace

La fenêtre de paramètres au lancement permet de relancer avec d'autres valeurs, par exemple pour convertir plusieurs jeux de données avec le même workspace. On la désactive avec le triangle à côté de Run. Dans le Translation Log, le nom du transformer est cliquable : il mène à l'élément du canevas qui produit le message.

Voir les données

L'icône verte est la copie locale des features (le feature cache). Un clic l'affiche dans la Visual Preview. Le FME Data Inspector offre la même vue en plein écran.

4Écrire des données

Ajouter un writer

Esri geodatabase (File Geodb Open API) [Writer]

Ce writer est utilisable par tout le monde.

Remplir le formulaire

Pour un reader, Dataset désigne les données à lire. Pour un writer, c'est le fichier ou le dossier où FME crée ou met à jour les données. Cocher Overwrite existing database pour écraser à chaque lancement. En mode Automatic, le writer reprend le schéma de ce qu'on lui connecte.

Relier le reader au writer feature type, puis régler la géométrie

User Attributes > Spatial definition > Geometry Type : geodb_point

Lancer une partie du flux

La petite flèche verte lance seulement une section du workspace.

Rassembler plusieurs flux dans un seul writer

Des flux reliés à la même entrée s'accumulent (union). Pour garder un seul feature type writer : modifie l'un d'eux (double-clic, nom, géométrie), relie tous les flux (par exemple tous les quartiers), supprime les autres writers, lance, puis vérifie que les données sont dans le même dossier.

6Inspecter les données

Voir les données écrites

Clique sur View written data sur le writer. Par le Navigator, un clic droit ouvre toute la geodatabase, avec toutes les couches.

Ajouter un fond de carte

Clic droit sur la carte de la preview. Les données doivent avoir un système de coordonnées, stocké ou explicite.

Explorer la Visual Preview

La géométrie est en vue graphique, les attributs en vue tableau. Le bouton toggle automatic inspect on selection garde l'affichage de la sélection. Tu peux changer la couleur et la taille des points. La preview sert à visualiser, ce n'est pas un vrai outil SIG pour faire des cartes.

Lire le tableau

Après le lancement, la quantité s'affiche dans le panneau. La colonne OBJECTID est ajoutée car une geodatabase Esri exige un entier unique non nul pour identifier chaque ligne. Un clic sur le nom d'une colonne la trie par ordre alphabétique. La barre de recherche en bas filtre, et le bouton colonnes en masque.

Colonne remplie de NULL ?

Regarde le writer : un attribut en rouge n'est relié à aucune source. Souvent, le nom contenait des espaces dans le reader et ils deviennent des _ dans le writer.

7Feature et 3D

Interroger une feature

La Feature Information affiche les attributs utilisateur, les attributs de format, le système de coordonnées et la géométrie. Un attribut exposé apparaît dans le tableau ou dans la table de destination, un attribut non exposé sert à FME sans y apparaître. Pour une feature spatiale, on lit aussi le résumé de la géométrie : dimension, nombre de sommets, étendue.

Passer en 3D

Le fond de carte ne s'affiche pas en 3D. Les outils Orbit font tourner l'objet. Exemple du cours : transformer des emprises de bâti 2D en modèles 3D avec un nuage de points au format LAS, qui ne gère pas les attributs définis par l'utilisateur.

Le piège

Le writer refuse un feature type dont le type de géométrie n'est pas défini (le log indique NO_GEOMETRY). Règle geodb_point dans les paramètres du writer feature type.

FileGDB Writer: Feature class 'BusinessOwners' has shape type ''
which is unknown to FME. Skipping feature class

Avec FME 25.0, aucune erreur ne s'affiche, mais le problème reste dans le workspace. Une erreur fatale arrête tout de suite le workspace et en provoque souvent d'autres.

À retenir

  • Dataset, feature type, feature, attribut : fichier, feuille, ligne, colonne.
  • Le système de coordonnées est facultatif, sauf pour un fond de carte.
  • Un writer a besoin d'un type de géométrie, sinon il ignore la couche.
  • Plusieurs flux reliés à un même writer s'additionnent.
  • La Visual Preview et la Feature Information servent à vérifier le résultat.

Chaque workspace commence par lire, écrire et regarder : tu y es.
