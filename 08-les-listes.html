FME

Les listes

Plusieurs valeurs dans un seul attribut

1Les définitions

Attribut liste
Le moyen de FME pour stocker plusieurs valeurs par feature. On l'écrit avec des accolades et un index qui commence à 0.
Modèle plat
Des tables qui ne stockent pas de relations avec d'autres tables (CSV, fichier texte).
Modèle relationnel
Des tables reliées par une relation définie, par exemple une clé commune.
Modèle objet
Les données sont stockées sur des objets, en paires clé-valeur.
Modèle imbriqué
Par exemple le JSON : il faut décider comment extraire les structures imbriquées.

2Écrire et lire une liste

La notation

Fruits{0} = Apple
Fruits{1} = Orange

Inspecter une liste

Dans la Feature Information (attributs exposés ou non exposés), chaque index et chaque valeur ont leur ligne. Une liste n'apparaît pas dans le tableau, elle contient trop de valeurs pour une cellule : on la sort avec des transformers.

Les modèles de données

FME traite le relationnel sans liste : chaque table est un feature type, chaque ligne une feature. Une liste devient nécessaire pour stocker une relation un-à-plusieurs sur une feature. Elle permet aussi de stocker des données orientées objet dans le cadre de FME fondé sur les features et les tables, et de traduire entre modèle objet et relationnel. Avec PythonCaller ou RCaller, une liste ou un tableau Python devient une liste FME.

3Quand en avoir besoin

Lire et écrire des données

Langages imbriqués (XML, JSON), valeurs de bandes d'un raster, métadonnées (XML ou liste).

Exprimer des relations

Par exemple lister dans store_names{} tous les magasins d'un quartier. Les transformers d'analyse spatiale, comme ceux de la famille Overlayer, génèrent souvent des listes.

Éviter les boucles

Avec un Cloner, on génère une feature par itération (un Tester teste la fin de la boucle). Une liste évite la boucle : on stocke toutes les valeurs dans la liste, puis on les explose, cherche, trie ou extrait. Une liste est plus rapide qu'une boucle, et plus simple avec un custom transformer.

4Créer une liste

Les façons d'en créer

À la main, automatiquement par un transformer, lue ou écrite par certains formats (XML, JSON), ou explosée en attributs à valeur unique. Un transformer crée une liste quand il regroupe des attributs de plusieurs features dans une seule.

L'option Generate List

Elle se trouve dans la section Attribute Accumulation. Elle augmente la taille des features et pèse sur la performance : coche-la seulement si besoin.

Exemple : les arbres des parcs

PointOnAreaOverlayer
Attribute Accumulation : décocher Merge Attributes
Generate List on Output 'Area' : _trees

Entrées : les arbres de rue (points) et les parcs (polygones). Avec Merge Attributes, le parc ne garde que l'attribut d'un seul arbre, ce n'est pas le but. Avec Generate List, le parc reçoit une liste _trees{} avec tous ses arbres.

6Exemple : le genre le plus fréquent

Objectif

Garder les parcs avec des arbres, trouver le genre le plus fréquent, puis le stocker dans un nouvel attribut.

Les étapes

1. Lire les arbres (points) et les parcs (polygones).
2. PointOnAreaOverlayer : une liste d'arbres par parc.
3. Garder les parcs avec des arbres : filtrer sur le champ de chevauchement supérieur à 0.
4. Combiner les listes avec un Aggregator (ou un ListBuilder) dans une liste _list.
5. Compter avec un ListHistogrammer : une liste _histogram, triée.
6. Stocker le résultat : AttributeCreator, FME Feature Attributes, Histogram.value, valeur {0}.

Sans liste

Clipper pour filtrer les arbres, StatisticsCalculator groupé par nom de genre, puis Sorter en numérique décroissant.

7Exercice : le JSON

JSON plat

Creator pour lancer le flux, puis JSONFormatter : tout le JSON sort sur une seule ligne. Avec JSONFeature on lit le JSON comme une feature FME, ListBuilder crée la liste de fruits avec leurs deux attributs (nom et nom scientifique), ListExploder en fait une table normale.

JSON imbriqué

La structure imbriquée est conservée. Lu avec JSONFeature, les attributs sont exposés mais invisibles dans le tableau, la sous-liste est un attribut. Un ListExploder affiche les éléments non liste, les éléments liste restent dans la Feature Information. Pour exploser la sous-liste, un second ListExploder la cible.

Pour utiliser le JSONFormatter, place un Creator en amont. Dans un PythonCaller, la méthode fmeobjects.FMEFeature.setAttribute() crée une liste FME à partir d'une liste Python.

Le piège

Avec Merge Attributes, le parc ne garde que les attributs d'un seul arbre. Pour garder tous les arbres, décoche Merge et coche Generate List.

Generate List alourdit les features et ralentit le workspace : coche-la seulement quand tu en as besoin.

À retenir

  • Une liste stocke plusieurs valeurs par feature, avec un index qui commence à 0.
  • Elle sert pour le JSON et le XML, les relations un-à-plusieurs et les analyses spatiales.
  • Une liste est plus rapide et plus simple qu'une boucle.
  • Generate List crée une liste dans un Overlayer, à cocher seulement si besoin.
  • Les transformers List... comptent, trient, cherchent, explosent et construisent.

Une liste bien manipulée remplace beaucoup de boucles : continue.
