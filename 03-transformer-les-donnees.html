FME

Transformer

Lire le web, mapper le schéma, filtrer

1Les définitions

Transformer
Un objet du canevas qui modifie, crée ou filtre les features qui le traversent.
Éditer le schéma
Définir le schéma voulu sur les données écrites, en changeant les paramètres du feature type.
Mapper le schéma
Relier l'ancien schéma au nouveau avec des transformers.
Upstream / downstream
Plus tôt dans le flux de données / plus tard dans le flux.

2Lire des données du web

Objectif du cours : lire des licences d'entreprises depuis une API et les écrire dans une geodatabase Esri.

Ajouter un Creator et un HTTPCaller

Le HTTPCaller a besoin d'une entrée. Le Creator crée une feature vide qui déclenche l'appel. Relie le Creator au HTTPCaller.

Régler le HTTPCaller

Méthode : GET
Response body encoding : system default (fme-system)

Colle l'URL. L'encodage garantit que le JSON est lu comme du texte et non comme un fichier binaire. Le bouton Send Test Request teste l'appel.

Lire la réponse

Le JSON est stocké dans l'attribut du corps de la réponse. Un statut HTTP 200 signifie que l'appel a réussi.

Ajouter un JSONFragmenter

Il découpe chaque entrée du tableau JSON en une feature. Avec Flatten Query Result into Attributes sur Yes, la structure imbriquée du JSON devient des colonnes. Les attributs obtenus sont non exposés, car FME exige un schéma fixe.

Ajouter un AttributeExposer

Import from Cache

Pour écrire du SQL ou du Python, utilise DatabaseQuerier ou PythonCaller. L'AI Assist aide à écrire une expression régulière. Le FeatureReader sait aussi exécuter des requêtes sur les bases SQL ou Cypher : choisis Custom Query dans Read Criteria By, les features sortent par le port Generic.

3Créer des points

Ajouter un VertexCreator

X Value = longitude
Y Value = latitude

Il passe d'un tableau à une géométrie de points.

Repérer le problème de coordonnées

Après le lancement, les points ne tombent pas sur le fond de carte. La vue graphique indique que des features n'ont pas pu être reprojetées et que le système vaut Unknown.

Régler le système de coordonnées

Utilise le paramètre du VertexCreator. S'il n'existe pas dans ta version, utilise CoordinateSystemSetter si tu connais le système, ou Reprojector si tu dois le changer.

Ajouter le writer

Esri Geodatabase (File Geodb Open API), avec Overwrite Existing Geodatabase pour relancer plusieurs fois. Ajoute des bookmarks et renomme les transformers si besoin.

4Éditer et mapper le schéma

Voir le schéma du writer

Double-clique sur le writer feature type. Deux options : Automatic (le schéma de la source) ou Manual (tu définis la destination, puis tu adaptes les features avec des transformers).

Éditer les attributs du writer

Supprimer tous les attributs, les déplacer avec les flèches, les renommer. Au lancement, les données manquent : il faut maintenant mapper la source vers la destination.

Mapper avec un AttributeManager

Il crée des attributs, renomme, change l'ordre, fixe des valeurs. Active le mode automatique du writer pour une sortie dynamique qui suit l'AttributeManager.

Lire les triangles du writer

Rouge : l'attribut existe sur le writer mais pas sur les features entrantes, sans erreur mais sans valeur. Jaune : un attribut du reader n'est relié à aucun writer, il n'apparaîtra pas. Vert : l'attribut est connecté.

Les paramètres d'un transformer sont codés par couleur : rouge à renseigner obligatoirement, jaune avec une valeur par défaut à relire, bleu à relire ou à régler.

5Créer et déboguer efficacement

Le feature caching

Mode d'édition du menu Run, activé par défaut. Un cache local est stocké sur chaque port de sortie : tu consultes et compares les données partout dans le workspace. Tu peux le désactiver dans le menu Run.

Les runs partiels

Run from this
Run Just this
Run To this
Run between selected

Ils lancent seulement une section du workspace. Un clic droit permet de vider le feature cache.

7Filtrer par valeurs d'attribut

Retirer des licences avec un AttributeFilter

Exemple du cours : enlever les quatre valeurs de licences révoquées. Les valeurs sont écrites en dur et il faut ajouter un reader.

Tester et TestFilter

Ils sont aussi écrits en dur : ce n'est pas une solution durable. Le Tester peut retirer une entreprise précise.

DatabaseJoiner

Il filtre sans ajouter un reader pour lire l'une des bases.

Le piège

Un filtre aux valeurs écrites en dur (AttributeFilter, Tester, TestFilter) ne suit pas les données : si les données sources changent, tu dois mettre à jour le workspace.

À retenir

  • Creator, puis HTTPCaller, puis JSONFragmenter pour lire une API.
  • Un VertexCreator crée des points, il faut ensuite régler le système de coordonnées.
  • Éditer le schéma définit la destination, mapper le relie à la source.
  • Les triangles rouge, jaune et vert du writer montrent l'état du mapping.
  • Le feature caching et les runs partiels accélèrent le débogage.

Un transformer à la fois : tu construis un flux solide.
