FME

Déboguer

Trouver et corriger les problèmes

1Les définitions

Débogage
Déterminer si un problème a eu lieu, puis le retrouver.
Post-mortem
Déboguer un processus après sa fin pour trouver la cause d'un échec fatal.
Log spatial
Un dataset (workspace.ffs) avec toutes les features citées dans le log, en plus du fichier texte workspace.log.

2L'ordre du débogage

Les quatre étapes

1. Chercher les problèmes : le log (avertissements et erreurs) et le dataset de sortie.
2. Localiser le problème : les nombres de features sur les connexions et les données aux étapes clés.
3. Déterminer le problème : les paramètres du reader, du writer et des transformers, et le workspace en mode feature debug.
4. Si tu ne trouves pas, faire un post-mortem avec l'option de tracing (débogage interactif).

Un exercice type

1. Vérifier la source, hors FME.
2. Vérifier le reader.
3. Vérifier transformer par transformer.
4. Vérifier le writer en dernier : ouvre les données dans un éditeur de texte ou dans Excel pour savoir si le problème vient de l'écriture et non de la visualisation.

3Lire le log

Error
Un problème a arrêté le traitement de FME.
Warning
En bleu, avec WARN. Le problème est parfois mineur : FME termine la traduction, mais mieux vaut vérifier.
Information
INFORM : indique si la traduction a bien fonctionné.
Statistics
Des chiffres sur la transformation.

Clique sur le nom du transformer dans le log pour zoomer sur la source du problème.

Le log spatial

Il se remplit avec les features rejetées quand Reader/Writer Redirect est activé (Navigator, Workspace Parameters), ou quand le Logger est réglé sur Log and record. Ouvre-le avec le FME Inspector ou la Visual Preview.

4Personnaliser et filtrer le log

Les horodatages

Tools, FME Options, Translation, réglage Log Timestamp Information : date absolue, heure absolue, temps cumulé, temps écoulé pour cette étape, type de message. Les horodatages repèrent les sections lentes.

Le log debug

Il enregistre davantage d'informations : active-le quand une erreur a déjà eu lieu et que tu cherches des détails, puis désactive-le (les fichiers de log grossissent). Il reste dans le workspace même quand tu le passes à quelqu'un.

Filtrer le log

Avec les boutons. Les options FME réduisent aussi la taille du log, au prix d'un historique restreint de la traduction.

Exercice : un problème d'encodage

Lance, va dans la section des avertissements du log et agis selon le message : vérifie l'encodage du writer dans le Navigator.

5Sorties et nombres de features

Inspecter la sortie

Format
Schéma : bonnes couches, catégories, classes ?
Géométrie : correcte ?
Symbologie
Attributs : tous présents ?
Quantité : bon nombre ?
Résultat : la transformation est-elle celle attendue ?

Même sans avertissement ni erreur, les sorties peuvent être fausses. Utilise la Visual Preview ou l'application de destination.

Les nombres de features

Ils indiquent à quel port le problème apparaît. Une feature qui disparaît est rejetée : consulte fme_rejection_code pour voir le problème.

Les étapes clés

Le workspace lit mal les données, les transforme mal, les écrit mal, ou une autre application les interprète mal.

Exercice : Unexpected input

Ce message apparaît quand FME lit des données absentes du workspace (par exemple un KML lu en entier alors qu'un seul feature type est choisi). Dans l'exemple du cours, le JSONExtractor posait problème car une entité avait une géométrie nulle : ajoute un Tester qui exclut les features à géométrie nulle.

En cas de problème de système de coordonnées, mieux vaut reprojeter.

Le piège

Un workspace qui se termine sans avertissement ni erreur peut produire des sorties fausses. Vérifie toujours le résultat.

À retenir

  • Ordre : chercher, localiser, déterminer, puis post-mortem si besoin.
  • Un message Error arrête FME, un Warning demande de vérifier.
  • Les horodatages du log repèrent les sections lentes.
  • Les nombres de features et le port Rejected localisent le problème.
  • Vérifie la source, le reader, les transformers, puis le writer.

Déboguer, c'est enquêter dans le bon ordre : tu as la méthode.
