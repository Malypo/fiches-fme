Paramètres

Paramètres FME et paramètres utilisateur

1Les définitions

Paramètre
Un contrôle qui définit comment FME fonctionne, par exemple comment un reader lit ou un transformer transforme.
Paramètre FME
Intégré à l'interface de FME Workbench, pour l'auteur du workspace.
Paramètre utilisateur
Créé par l'auteur pour que l'utilisateur donne ses propres valeurs.

2Auteurs et utilisateurs

L'auteur

Il conçoit le workspace et règle les paramètres FME pour contrôler l'exécution. On les trouve dans les dialogues de transformers, de feature types et dans le Navigator.

L'utilisateur

Il utilise un workspace qu'il n'a pas créé, souvent avec peu de connaissances de FME. Il a besoin de paramètres utilisateur.

Les presets

Le bouton Preset en bas d'un dialogue de paramètres applique les mêmes valeurs à plusieurs transformers, readers ou writers (un mot de passe, une tolérance).

3Créer un paramètre utilisateur

Deux chemins

Navigator, User Parameters, Manage User Parameters
Pré-lié : clic droit sur un paramètre FME, Create User Parameter, ou la flèche dans un dialogue de transformer

La première voie propose beaucoup de types. La seconde est rapide et lie directement le paramètre, mais elle est moins flexible : on ne choisit pas le type (pour un format générique, l'utilisateur aura toute la liste).

Les copier

On peut copier, coller et dupliquer des paramètres utilisateur entre workspaces, définition comprise.

4Les utiliser

Où ils servent

Liés à un paramètre FME, comme valeur pour des transformers, ou comme valeur d'attributs.

Les saisir

Menu Run, Enable Prompt for parameters. On peut aussi passer par l'API REST de FME Flow.

FME ne propose le prompt que si le workspace exécute une partie utilisant un paramètre publié. Lors d'un run partiel, il peut ne pas servir si les données viennent du cache.

5Exercice : paramétrer un workspace

Le contexte

Un workspace traduit des parcs MapInfo vers KML et écrit un XML de métadonnées. Le XML est mal formaté et les métadonnées sont codées en dur dans un AttributeCreator, ce qui gêne sur FME Flow.

Les étapes

Paramètre de sortie : Pretty print sur Oui
Navigator, User Parameters, Manage : créer le premier, dupliquer les autres
Méthode 1 : dans l'AttributeCreator, flèche, User Parameter
Méthode 2 : ParameterFetcher après l'AttributeCreator
Run, Enable Prompt for parameters

Un Sampler permet de n'avoir qu'un polygone pour insérer les métadonnées. Pour valider une adresse e-mail, un StringSearcher ou un AttributeValidator après le ParameterFetcher teste une expression régulière.

À retenir

  • Paramètre FME pour l'auteur, paramètre utilisateur pour l'utilisateur.
  • On crée un paramètre utilisateur depuis le Navigator ou directement depuis un paramètre FME.
  • Le Prompt for parameters se coche dans le menu Run.
  • ParameterFetcher met la valeur d'un paramètre dans un attribut.
  • Un paramètre utilisateur se duplique et se copie entre workspaces.

Un bon paramètre évite à ton collègue d'ouvrir le workspace.
