FME

Types

Texte, nombre, choix et liens

1Les définitions

Linking
Relier un paramètre utilisateur à un paramètre FME pour que la saisie de l'utilisateur s'applique directement.
Direct link
Créer et lier un paramètre en une seule étape.
Pré-lié
Un paramètre créé et lié automatiquement par FME, par exemple à l'ajout d'un reader ou d'un writer.

2Les paramètres texte

Les options

Plain Text Uniline : une ligne
Text Multiline : plusieurs lignes
Trim Whitespaces : retire les espaces au début et à la fin

Aucune limite de caractères. La syntaxe de l'éditeur contrôle les valeurs acceptées et colore le code. Un StringReplacer dans le workspace retire les éléments indésirables (virgules, délimiteurs).

Tous les transformers ne gèrent pas le texte encodé FME du Plain Text Multiline : l'Uniline est plus sûr et universel.

3Les paramètres nombre

Un seul type

Number, au choix flottant (précision numérique) ou entier. On peut fixer une limite haute et basse pour vérifier que la saisie convient.

4Les paramètres choix

La liste fixe

Une liste d'options. Attention à la distinction entre la colonne Value (que le transformer garde) et la colonne Display (que l'utilisateur voit).

Les affichages

Dropdown : une valeur dans une liste
List : cases à cocher, multi-sélection
Tree : liste imbriquée avec « . » dans Display, multi-sélection

Pour proposer des formats de reader, de writer ou des systèmes de coordonnées, utilise le bouton Import du paramètre Choice et ne garde que ceux voulus : moins d'erreurs.

5Lier un paramètre

La liaison manuelle

Clic droit sur le paramètre FME dans le Navigator, Link to a parameter, puis le paramètre utilisateur. On peut délier.

Le lien direct

Clic droit sur un paramètre FME, Create User Parameter, ou depuis la flèche d'un dialogue de transformer. La définition est remplie et le type est fixé. Avantage : une seule étape et le bon type de données. Inconvénients : impossible de choisir le type, le paramètre dépend toujours du transformer (si tu le supprimes, il disparaît), et pas de contrôle sur l'assignation d'attributs.

Les pré-liés

FME les crée et les lie automatiquement (reader, writer, feature types à lire) pour l'utilisateur. On ne peut pas les supprimer.

Lier depuis l'endroit du paramètre FME est en général plus rapide que clic droit sur le paramètre utilisateur puis Apply to : la liste des paramètres FME à choisir y est bien plus longue.

À retenir

  • Texte : Uniline est le plus universel.
  • Nombre : entier ou flottant, avec des limites pour valider.
  • Choix : Value est ce que FME garde, Display ce que l'utilisateur voit.
  • Le lien direct est rapide mais le paramètre reste attaché au transformer.
  • Un paramètre pré-lié ne se supprime pas, le reader ou writer reste.

Le bon type de paramètre : la moitié de la validation est déjà faite.
