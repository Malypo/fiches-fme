Custom flexibles

Attributs et paramètres dans un custom transformer

1Les définitions

Attribute References
Le paramètre qui décide comment le custom transformer gère les attributs en entrée.
Handle with Published Parameters
Réglage automatique : chaque attribut référencé dedans est géré à l'extérieur.

2Attributs et paramètres en entrée

Par attributs

Beaucoup de paramètres de transformers acceptent des attributs. Si l'attribut n'est pas disponible, le transformer est Incomplete.

Par paramètres utilisateur

Le problème est la duplication : si chaque instance utilise le même paramètre, toutes reçoivent la même entrée. Il faut un mécanisme pour entrer des valeurs différentes par instance.

3La gestion automatique

Les paramètres utilisateur

Quand un transformer avec un paramètre utilisateur publié est mis dans un custom transformer, le paramètre passe du navigateur principal à celui du custom. L'utilisateur n'est plus sollicité à l'exécution, et on peut le régler différemment pour chaque instance. S'il faut une saisie au runtime, on publie le paramètre (alors partagé, même valeur).

Les attributs

À la création, Attribute References vaut Handle with Published Parameters : chaque attribut référencé dedans est supporté dehors, avec un paramètre utilisateur par attribut. Dedans c'est un nom d'attribut, dehors un paramètre utilisateur. Dans un endroit sans l'attribut requis, le transformer est incomplet, mais l'auteur peut choisir un attribut disponible.

4Après la création

Les attributs entrants

Clic sur le port d'entrée et exposer un lien d'attribut externe vers le custom : les attributs exposés deviennent des paramètres utilisateur sur le canevas principal.

Les attributs sortants

Clic sur le port de sortie pour cacher ceux qu'on ne veut pas, par exemple ceux d'un calcul intermédiaire.

Le mode Fix Manually

Avec Fix Manually (Advanced), le workspace ne tourne pas par défaut, car aucun attribut n'est disponible dans le custom. On ne peut plus choisir d'attribut depuis l'onglet principal. L'auteur doit exposer les attributs à la main. Le custom ne marche pas sur un autre schéma, sauf si les attributs exposés sont aussi publiés.

5Les bonnes pratiques

Simple

Les paramètres rendent les custom transformers plus puissants mais plus complexes : aussi simples que possible. Si le nombre de choix devient énorme, on divise le custom transformer.

Les outils

Les types de paramètres valident la saisie (parfois il faut ajouter la validation au workspace)
La visibilité conditionnelle imbrique les fonctions
Moins de décisions de haut niveau
Les Group Boxes cachent la complexité (Parameter Manager)

6Exercice : une densité plus générique

Le nom de sortie

Deux instances produisent toutes deux DensityResult. Dans l'onglet du custom, ExpressionEvaluator, on crée un paramètre utilisateur pour le nom. L'option apparaît alors sur le custom du canevas principal, et on peut les mettre en série.

L'attribut d'entrée

Onglet custom, ouvrir Input, ajouter Population et décocher les autres attributs externes.

Les unités

Nouveau paramètre via le Navigator (le menu déroulant), utilisé comme multiplicateur dans l'AreaCalculator.

La pondération

Un RandomNumberGenerator sur le canevas principal, exposé dans Input Parameter du custom. On rend le weightedattribute requis et on efface la valeur par défaut. Tester après l'aire : si le poids est supérieur à 0, on l'utilise dans l'ExpressionEvaluator.

On utilise l'attribut dans l'expression, pas le paramètre publié : FME gère ce comportement automatiquement, avec une fonctionnalité cachée qui remplace l'attribut. Autre option : créer directement un paramètre Attribute Name dans le custom.

À retenir

  • Handle with Published Parameters rend le custom transformer utilisable sur n'importe quel schéma.
  • Un paramètre publié dans un custom reste dans le dialogue du custom.
  • Expose les attributs entrants dans le port d'entrée, cache les sortants dans le port de sortie.
  • Fix Manually est avancé : l'auteur doit tout exposer lui-même.
  • Garde les paramètres simples, divise si ça devient trop gros.

Un custom transformer flexible, c'est un outil que les autres osent utiliser.
